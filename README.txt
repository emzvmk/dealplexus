DealPlexus | Global Financial Command Centre

Open index.html in Chrome, Edge, Safari or Firefox. No install or server needed.

Files
  index.html          page shell
  css/style.css       all styling (dark green theme)
  js/app.js           dashboard code: calculation engine, data, all 10 sections
  js/vendor/          libraries bundled for offline use (React 18.3.1, Recharts 2.12.7, globe.gl 2.39.7)

Notes
  - Fonts (Montserrat, Nunito Sans, IBM Plex Mono) load from Google Fonts; offline, system fonts are used.
  - The 3D globe needs WebGL; without it a flat map is shown.
  - Country and market figures are static, with source links and the date checked (29 Oct 2026). Not legal advice.
  - Export CSV shows the data to copy when file saving is unavailable.
